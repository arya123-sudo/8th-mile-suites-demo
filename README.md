# Hotel 8th Mile Suites — Demo Website

A demo website built for **Hotel 8th Mile Suites**, a hotel in T. Dasarahalli, Bengaluru.

The page showcases the hotel's rooms, amenities, and ratings, with a "Book Direct & Save" strip and WhatsApp enquiry buttons so guests can book directly instead of through commission-charging aggregators.

> **Note:** The rooms, tariffs, and details shown on this demo page are sample placeholders. They will be replaced with the hotel's actual rooms and rates before the final handover.
